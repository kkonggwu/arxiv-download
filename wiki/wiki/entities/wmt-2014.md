# WMT 2014

WMT 2014 是 [[transformer]] 论文使用的主要机器翻译评测数据集，包含两个语言对任务。

## 任务与规模

- WMT 2014 English-to-German：约 4.5M 句对；使用 byte-pair encoding 共享词表约 37000 tokens。
- WMT 2014 English-to-French：36M 句；使用 word-piece 词表 32000。

## 评测集

- newstest2014：主测试集，用于报告 BLEU。
- newstest2013：开发集，用于模型变体对比（Table 3）。

## 论文报告结果

- 英德 newstest2014：Transformer base 27.3 BLEU，big 28.4 BLEU。
- 英法 newstest2014：Transformer base 38.1 BLEU，big 41.8 BLEU（正文一处写 41.0）。
